이렇게 써요

예시를 보고 싶은 곳을 고르세요.

  1. 지출 버튼을 누르고 말하기

    평소 말투 그대로 괜찮아요. 몇 건을 한 번에 말해도 나눠서 적어요.

    말한 그대로팀홀튼 커피 2불 15
    함께한 사람·식사까지수환 형님하고 코리아하우스에서 저녁 먹었어 85불
    여러 건 한 번에모기지 2100불 그다음 관리비 650불
    말한 그대로메가커피 아메리카노 2,000원
    함께한 사람·식사까지친구랑 김밥천국에서 점심 먹었어 만 이천 원
    여러 건 한 번에월세 육십오만 원 그다음 관리비 이십오만 삼천 원
  2. 확인하고 저장

    앱이 알아들은 내용을 문장으로 보여줘요. 맞으면 저장, 틀리면 고치면 돼요. 고친 말은 다음부터 기억해요.

    이렇게 기록돼요수환 형님과 코리아하우스에서 저녁식사를 했어요 · $85.00
    이렇게 기록돼요친구와 김밥천국에서 점심식사를 했어요 · 12,000원
  3. 궁금하면 물어보기

    목록을 뒤질 필요 없이 질문하면 계산해서 알려줘요.

    이번 달 커피 지출은 총 얼마야?

깜빡한 지난 날짜

“어제”, “지난 금요일”, “10월 31일” 이라고 말하면 그 날짜로 적어요.

원 · 달러

“1불99”, “5불 45센트”, “사만오천육백칠십 원”, “3억” 모두 OK.

누구와, 어떤 식사

“김부장님이랑 점심” 처럼 말하면 사람과 식사도 따로 기록.

고친 말을 배워요

받아쓰기가 틀린 가게 이름·물건을 한 번 고치면 다음부터 알아서.

예산과 차트

식비·커피 한도를 정하면 80%·100%에서 알려주고, 지난달과 비교해 보여줘요.

요약 · 월급날 알림

하루·한 주·한 달 합계와 월급(주급) 입금일을 알려줘요.

엑셀로 내보내기

달마다 요약과 전체 기록을 엑셀 파일로 받아요.

자동 분류

커피·식비·장보기·교통·주거 등 15가지로 알아서 나눠요.

솔직히 알려드려요

  • 카드·은행 내역을 자동으로 가져오지 않아요.내가 말한 것만 적어요. 그래서 더 가볍고 안전하지만, 쓴 돈은 직접 말해야 해요.
  • 기록은 그 폰 안에만 있어요.폰을 바꾸거나 앱을 지우기 전에 설정 → "백업 파일 저장"을 꼭 해 두세요. 한 달에 한 번 권해요.
  • 받아쓰기는 가끔 틀려요.저장 전에 한 번 확인하세요. 고친 말은 앱이 기억해요.
  • 앱스토어 앱이 아니에요.웹 주소를 홈 화면에 추가해서 앱처럼 써요. 설치는 아래처럼 1분이면 돼요.

설치하기 (1분)

  1. Safari로 이 페이지를 열어요카카오톡에서 열었다면 오른쪽 아래 또는 ⋯ → "Safari로 열기"
  2. 화면 아래 공유 버튼을 눌러요
  3. 목록을 내려서 홈 화면에 추가 → 추가영어 설정이면 "Add to Home Screen"
  4. 홈 화면의 오늘 얼마 썼어? 아이콘으로 열고, 처음 마이크를 누를 때 허용을 눌러요
  1. Chrome으로 이 페이지를 열어요카카오톡에서 열었다면 오른쪽 위 → "다른 브라우저로 열기"
  2. 오른쪽 위 메뉴를 눌러요
  3. 홈 화면에 추가 또는 앱 설치 → 설치삼성 인터넷이면 아래 메뉴 ≡ → "현재 페이지 추가" → "홈 화면"
  4. 홈 화면의 오늘 얼마 썼어? 아이콘으로 열고, 처음 마이크를 누를 때 허용을 눌러요
마이크가 안 되면? 입력칸을 누르고 키보드의 🎤 버튼으로 말해도 똑같이 기록돼요.

처음 한 번만 설정

설정 → 백업 파일 저장을 한 달에 한 번 해 두면 안심이에요.
